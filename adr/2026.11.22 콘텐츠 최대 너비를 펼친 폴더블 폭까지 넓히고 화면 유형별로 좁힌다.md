# 콘텐츠 최대 너비를 펼친 폴더블 폭까지 넓히고 화면 유형별로 좁힌다

- 결정일: 2026-11-22
- 대상: `src/style/globals.css`(`--content-max-width`), `tailwind.config.ts`(`max-w-content`, `screens.fold`), `src/components/ui/Layout/ContentWidth.tsx`, 공통 고정 UI(Navbar, SideFilterDrawer, 모달·바텀시트)
- 관련 이슈: https://github.com/bottle-note/workspace/issues/451

## Context(배경)

아이폰 듀오를 펼치면 Safari가 웹 화면에 669px(세로)·951px(가로)을 준다. 콘텐츠 최대 너비가 468px로 고정돼 있어 펼친 화면에서도 가운데 468px만 쓰고 양옆이 비었다.

- Given 펼친 듀오(세로 669px) 사용자 / When 주요 화면을 열면 / Then 콘텐츠가 화면 폭을 채운다. 합격 기준: 669px에서 콘텐츠 폭이 화면 폭과 같고 가로 스크롤이 없다.
- Given 768px보다 넓은 화면 / When 같은 화면을 열면 / Then 콘텐츠는 가운데 768px에 머물고 양옆은 배경으로 남는다. tablet 전용 배치는 아직 시안만 있고 구현하지 않는다.

입력 화면을 768px로 늘리면 입력 칸과 버튼이 지나치게 길어진다. 바텐더 노트·위스키 MBTI·타로처럼 단계별 전체 화면 흐름은 넓은 화면 시안이 없다.

## Decision(결정)

- 화면 구간은 mobile(기본, 480px 이하)·`fold`(481px 이상)·tablet(768px 이상, 보류)으로 나눈다. `fold`는 Tailwind 기본 `sm`보다 앞에 둔다. 새 반응형 작업은 `sm`·`md`를 쓰지 않는다.
- 콘텐츠 최대 너비는 CSS 변수 `--content-max-width`(기본 768px)로 둔다. `max-w-content`, `.fixed-content`, `.content-container`가 모두 이 변수를 읽는다.
- 화면 유형별 너비는 변수를 덮어써서 정한다. 입력·설정·약관 화면은 `.content-width-form`(560px), `(custom)` 그룹은 `.content-width-mobile`(468px)을 쓴다. route에서는 `ContentWidth` 컴포넌트를 segment layout에 둔다. 변수는 DOM으로 상속되므로 화면 안의 `fixed-content` 헤더·하단 버튼도 같은 너비를 따른다.
- `#modal`이나 라이브러리 포털로 뜨는 오버레이는 DOM으로 변수를 상속받지 못한다. `ContentWidth`가 같은 값을 React context로도 내려주고, `BackDrop`은 그 클래스를 포털 루트에 붙인다. 모달·바텀시트는 560px를 넘지 않고, 468px 화면에서는 468px를 따른다.
- 필터 서랍은 콘텐츠 폭으로 잘라낸 고정 영역 안에서 열려, 양옆 배경 위로 미끄러져 들어오지 않는다. 플로팅 버튼은 `.right-content-edge`로 콘텐츠 영역의 오른쪽 끝에 맞춘다.
- 하단 내비 메뉴는 600px 안에서 가운데 정렬한다.

### Rejected Alternatives(선택하지 않은 대안)

- 고정값 `max-w-content: 768px` 하나만 바꾸기: 입력 화면과 전용 흐름이 함께 늘어나고, 각 화면의 고정 헤더·하단 버튼을 일일이 다시 맞춰야 한다.
- 접힘 상태 감지(Viewport Segments·Device Posture API): Safari 27.1이 지원하지 않는다.

## Status(상태)

Accepted(승인됨)

## Consequences(결과와 영향)

- 너비를 바꿀 때는 `globals.css`의 변수와 `src/constants/imageSizes.ts`의 `sizes` 값을 함께 바꾼다.
- 새 고정 UI는 `fixed left-0 right-0` 대신 `fixed-content`를 써야 화면 유형별 너비를 따른다.
- 목록 열 늘리기 같은 화면별 fold 배치는 후속 PR에서 화면 단위로 적용한다.

Bottle Note — Editorial redesign / 2026.10.01

실제 페이지처럼 이동하는 18개 HTML 화면입니다.
선택한 1안의 책갈피·노트 구성을 바탕으로 홈 배너, 목록, 평가와 기록 흐름을 다시 정리했습니다.

후속 개선
- 둘러보기: 중복 제목 제거, 검색 바로 아래 카테고리, 제품별 풍미 표시.
- 리뷰: 병 사진과 글을 함께 보여주는 피드, 리뷰 쓰기 바로 가기.
- 시음회: 전체 보기 추가, 일정·장소·가격과 읽을거리 노출.
- 마이보틀: 짧은 프로필 아래 전체·별점·리뷰·찜 책갈피, 나의 리뷰 미리 보기.
- 수입통관: 수입 내역·수입사 목록과 각각의 상세 화면, 기간·제조국 필터와 검색. 모바일 둘러보기에 진입 버튼 추가.
- 수입통관 톤 재수정: 둘러보기의 병 사진·제품명 목록 스타일, 마이보틀의 책갈피·검색 배치와 짧은 소개를 재사용. 큰 날짜 강조 제거.
- 홈의 승인된 구성을 유지합니다.

열기
1. 압축을 풀고 이 폴더에서 정적 웹 서버를 실행합니다.
   Python이 있다면: python3 -m http.server 8080
2. 브라우저에서 http://localhost:8080/index.html 을 엽니다.
HTML, CSS, JavaScript, 이미지, 폰트가 모두 포함되어 별도 빌드는 필요 없습니다.
file://로 직접 여는 방식은 이번 검증 범위에 포함하지 않았습니다.

추천 확인 순서
홈 → 위스키 선택 → 별점/찜 → 리뷰 쓰기 → 리뷰 상세 → 마이보틀
설정에서 라이트/다크를 바꿀 수 있습니다. 웹에서는 상단 달/해 아이콘도 동작합니다.
390px 모바일, 834px 중간 폭, 1440px 웹을 확인했습니다.
700px부터 옆 메뉴와 목록 2열을 사용합니다. 세부 작성 폼은 공간이 확보되면 2열이 됩니다.

새로 꺼내 놓은 기존 기능
- 홈: 취향 테스트, 위스키 타로, 최근 본 위스키, 나의 기록
- 상세: 찜, 리뷰 쓰기, 공유, 수입 정보
취향 테스트와 타로는 실제 보틀노트의 별도 페이지를 새 탭으로 엽니다.
해당 기능 전체를 이 HTML에 복제하지 않았습니다.

디자인 기준
- 큰 배너와 절제된 선·여백, 사진과 제목의 위계: 29CM 공식 사이트 참고
- 평균 별점과 개인 별점 구분, 아이콘+텍스트 행동 묶음: 왓챠피디아 상세 참고
- 보틀노트의 SUIT, 코랄, 오크 계열 다크 토큰 사용
- 기존 책갈피 탭, 별점 입력, 별점 표시, 버튼, 검색 컴포넌트 직접 사용
- 병 사진은 흰 배경까지 포함한 원본 비율로 표시
- 내비게이션 아이콘은 Lucide 원본, 나머지 제품 아이콘은 기존 소스 사용

기능과 데이터 범위
실제 서버와 연결하지 않는 디자인 시안입니다. 내용·별점·행사·수입 내역은 예시입니다.
찜, 별점, 작성 리뷰, 댓글, 프로필 편집은 현재 브라우저 탭의 sessionStorage에 보관됩니다.
새 탭·다른 기기·실제 보틀노트 계정에 저장되지는 않습니다.
화면 모드는 localStorage에 저장됩니다.
실제 인증을 우회하거나 API를 가로채지 않습니다.
로그인·취향 테스트·타로 등 외부 페이지의 전체 동작은 이번 검증 범위 밖입니다.
설정의 알림 토글은 화면 예시이며 실제 알림 설정을 변경하지 않습니다.
시음회 신청/결제는 연결하지 않고 예시 안내를 표시합니다.

구현 메모
운영 앱의 화면 코드는 수정하지 않았습니다.
real-ui.js와 product-ui.css는 기존 제품 컴포넌트를 묶은 정적 번들입니다.
각 HTML에는 렌더링된 화면 마크업도 포함되어 있습니다.
src/ 및 build.mjs는 저장소 내에서 시안을 다시 편집할 때 사용합니다.
공유본을 열 때는 이 소스 파일을 빌드할 필요가 없습니다.

1. [P1, 수정] 모바일 홈에서 배너 글자가 병·잎 사진과 겹쳤다. 모바일 사진 정렬을 왼쪽으로 바꾸고 카피 폭을 제한했다. 두 번째 배너는 사진과 카피 영역을 나눴다. `screenshots/home-mobile-light.png`에서 글자와 이미지 분리를 재확인했다.

## 브라우저 검증

Playwright MCP로 확인했다. 운영 로그인/서버 요청을 목킹하지 않았다.

- 18개 페이지 × 390/834/1440px × 라이트/다크 = 108가지 조합: 가로 넘침, 화면 밖 일반 콘텐츠, 깨진 이미지, pageerror 모두 0. 자세한 결과는 `qa-results.json`.
- 최종 핵심 화면 9개 재캡처 과정에서 console error 0.
- 홈 책갈피 탭 전환: 최근 본 위스키 2개, 시음회·프로그램 2개 표시.
- 찜 버튼 변경 후 상세 이동, 별점 키보드 입력, 리뷰 작성 화면 연결.
- 별점·본문·풍미·장소 입력 → 리뷰 등록 → 상세 표시 → 댓글 작성 → 마이보틀의 내 리뷰 표시.
- 검색 결과 1개 표시 → 없는 검색어의 빈 상태 → 카테고리 필터 3개 표시.
- 설정에서 다크 전환 후 홈으로 이동해 테마 유지.
- 상세 공유 버튼을 눌러 링크 복사 완료 메시지 확인.
- 취향 테스트/타로 링크가 실제 기존 서비스 경로를 가리키는지 확인.
- 정적 HTML 내 화면 마크업 저장 후 다시 열어 렌더링과 탭 동작 확인.

## 의도한 범위와 남은 확인

- 디자인용 예시 데이터이며 실제 서버 저장·실제 계정 권한·프로덕션 데이터 정합성을 검증한 결과가 아니다.
- Flutter WebView, 실제 폴더블 기기의 접힘·힌지·화면 키보드 동작은 확인하지 않았다.
- 인증, 알림 전달, 행사 신청/결제, 외부 MBTI·타로 전체 플로는 이번 HTML 검증 범위 밖이다.
- 브라우저 확대/스크린리더 전체 검사는 수행하지 않았다. 실제 앱 반영 시 별도 접근성 검증이 필요하다.
- 실제 배너가 더 늘면 카피 길이와 이미지 초점을 배너별로 다시 확인해야 한다.

# 모바일 글자·버튼 기준 검토안

2026-09-24. 검토 후 DESIGN.md에 반영할 제안이다. 현재 구현된 토큰이나 컴포넌트 API를 뜻하지 않는다.

## 범위

탐색·상세·입력 화면에 공통으로 사용하는 글자와 버튼을 먼저 정한다. 기준 화면은 390×844이며, 적용 시 320px 너비와 최대 콘텐츠 폭 468px에서도 확인한다. 모바일 웹·WebView가 같은 시각 기준을 사용한다.

SUIT, 코랄 브랜드색, 본문 좌우 20px, 기존 4·8·12·16·32px 관계별 간격은 유지한다. 기본 버튼 높이 52px·모서리 12px도 유지한다. 아래 변경은 승인 후 관련 화면에 적용하며, 현재 제품 코드를 일괄 변경하지 않는다.

## 1. 글자 위계

모든 값은 px이며 굵기는 SUIT의 숫자 weight다. 자간은 기본값을 사용한다. 문구의 길이에 따라 글자를 축소하지 않고 줄바꿈과 배치를 조정한다.

| 역할           | 크기 / 줄 높이 / 굵기 | 적용 대상                                     |
| -------------- | --------------------- | --------------------------------------------- |
| 화면 대표 제목 | 20 / 26 / 800         | 상세 콘텐츠 제목, 화면을 소개하는 제목        |
| 앱 바 제목     | 16 / 20 / 700         | 뒤로 가기 헤더 가운데 제목                    |
| 섹션 제목      | 16 / 22 / 700         | 리뷰·기본 정보·선택 입력 등 정보 묶음         |
| 항목 이름      | 15 / 20 / 700         | 주류 이름, 일반 목록·카드의 대상 이름         |
| 본문           | 15 / 22 / 400         | 리뷰 내용, 일반 설명                          |
| 입력값         | 16 / 24 / 400         | 검색·입력창·리뷰 본문 작성                    |
| 부가 정보      | 13 / 18 / 400         | 영문 보조명, 리뷰 작성 날짜, 짧은 입력 도움말 |
| 중요 안내      | 15 / 22 / 400         | 신청 조건, 환불 안내, 입력 오류와 해결 방법   |
| 조작 문구      | 15 / 20 / 700         | 주요·보조 버튼, 탭, 선택 문구                 |
| 정보 배지      | 12 / 16 / 700         | 카테고리·상태를 짧게 표시하는 배지            |
| 강조 수치      | 24 / 28 / 800         | 개인 기록 집계 등 영역의 중심 값              |

부가 정보는 ‘리뷰 작성 날짜’, 한글 주류명 아래의 영문 이름, ‘최대 5장까지 첨부할 수 있어요’처럼 핵심 내용을 보완하는 짧은 정보다. 신청 조건·환불 안내·입력 오류처럼 판단이나 작업 완료에 필요한 내용은 아래쪽에 배치되더라도 중요 안내 규격을 사용한다. 중요한 문구는 보조색으로 약하게 표시하지 않고 본문 색상을 사용한다.

평점이 목록의 보조 정보이면 부가 정보 규격을 사용한다. 숫자라는 이유만으로 강조 수치를 적용하지 않는다. 이미지 커버 제목은 사진과의 관계를 고려하는 별도 유형으로 유지한다. 위 표를 모든 커버·로고·하단 메뉴에 일괄 대입하지 않는다.

### 기존 화면에서 달라지는 점

- 리뷰 본문 15/19px를 15/22px로 바꿔 여러 줄의 읽기 간격을 확보한다. 4줄이면 글 영역이 약 12px 늘어나므로 목록 높이도 달라진다.
- 입력창의 Noto Sans 지정을 SUIT로 통일한다. 리뷰 입력 행간은 20px에서 24px로 늘리되 기존 외곽 높이 192px는 유지한다. 같은 영역에서 보이는 줄 수는 줄어든다.
- 제목·항목·본문·보조 정보의 굵기를 역할별로 정한다. 설정의 작은 그룹 제목 등은 새 섹션 제목 규격으로 바뀌어 위계가 뚜렷해진다.
- 기본 확인·취소 버튼은 모두 15/20px·700으로 맞춘다. 현재 확인 15/19px, 취소 16/24px의 차이를 없앤다.
- 10~11px 정보 배지는 12px로 맞추되 정보 배지에 한정한다. 배지 너비와 줄바꿈이 늘 수 있어 카드 제목 영역과 함께 확인한다.
- 프로필의 강조 집계는 현재 27/31px에서 24/28px로 줄이는 제안이다. 프로필 이미지·이름보다 과도하게 강조되지 않게 하며 대표 화면에서 비교 후 결정한다.

## 2. 버튼의 행동 위계

공통 Button의 size와 variant 조합은 DESIGN.md의 입력·버튼 기준을 따른다.

| 역할      | 사용 조건                                    | 표현                                                                          |
| --------- | -------------------------------------------- | ----------------------------------------------------------------------------- |
| 주요      | 저장·등록·신청 등 화면의 중심 행동           | 코랄 단색 배경, 흰 글자                                                       |
| 보조      | 취소·이전·태그 추출·등록 등 주요 행동을 보완 | 기본 표면, 코랄 글자, 1px 코랄 테두리                                         |
| 텍스트    | 더 보기·도움말·부가 정보 이동                | 채움과 외곽선 없이 중립색 글자, 필요한 경우 아이콘                            |
| 위험 행동 | 삭제·탈퇴 등 되돌리기 어려운 행동            | 일반 주요 버튼과 구분하며 기존 위험 행동 표현을 사용; 공통 상태색은 별도 결정 |

코랄 배경·흰 글자는 유지한다. 코랄 채움 버튼은 화면의 핵심 행동에 제한해서 사용한다.

취소·확인 쌍은 기존처럼 같은 높이·균등 폭·간격 8px를 사용한다. 취소를 왼쪽, 확인을 오른쪽에 둔다. 주요 행동의 우선순위는 크기 차이보다 채움으로 표현한다.

리뷰 작성에서 ‘리뷰 등록’은 코랄 채움, ‘태그 추출·등록’은 코랄 외곽선으로 표시한다. 검색·필터·탭의 선택 상태는 화면의 제출 행동과 구분한다.

### 크기

| 유형                   | 높이 / 모서리 | 배치                              |
| ---------------------- | ------------- | --------------------------------- |
| 기본·하단 제출         | 52 / 12       | 부모 폭, 하단 고정은 본문 좌우 20 |
| 입력 옆 짧은 보조 행동 | 28 / 6        | Small, 내용에 따른 너비           |
| 콘텐츠 내 독립 행동    | 40 / 8        | Medium, 필요 시 부모 폭           |

일반 행동 버튼은 Small 28px, Medium 40px, Large 52px를 사용한다. 아이콘·탭·선택 요소에 같은 크기를 일괄 적용하지 않는다.

## 3. 색상과 상태

기존 팔레트를 사용하고 아래 조합을 버튼용 역할에 매핑한다. 공통 토큰을 바꾸기 전 배지 등 다른 사용처에 미칠 영향을 확인한다.

| 상태           | 표현                                                                                          |
| -------------- | --------------------------------------------------------------------------------------------- |
| 기본 주요 버튼 | 코랄 배경 + 흰 글자                                                                           |
| 눌림           | 기존 pressed 배경 역할 사용, 크기·위치·글자색 유지                                            |
| 선택           | 선택 표식·체크 또는 경계 변화와 색상을 함께 사용                                              |
| 비활성         | light: neutral-200 배경 + neutral-800 글자; dark: oak-800 배경 + oak-200 글자; 눌림 반응 없음 |
| 처리 중        | 버튼 크기 유지, 진행 표시와 ‘저장 중’ 같은 문구, 중복 실행 방지                               |
| 키보드 포커스  | 2px 포커스 링과 2px 바깥 간격; 레이아웃 크기에 영향 없음                                      |

현재 밝은 테마의 비활성 배경과 글자는 모두 neutral-600이다. 제안 조합은 두 색을 분리하면서 문구를 계속 읽을 수 있게 한다. 비활성 이유가 바로 이해되지 않으면 입력 근처에 설명을 제공한다.

## 4. 검토할 결정

1. 본문 15/22px·입력 16/24px를 포함한 글자 역할별 규격을 적용할지.
2. 12px 정보 배지와 24px 강조 집계처럼 시각 크기가 달라지는 항목을 적용할지.

검토 후 합의한 기준을 DESIGN.md에 반영한다. 첫 적용은 탐색 목록·상세 정보·리뷰 입력의 대표 화면에서 글자와 행동 위계를 비교하고, 이후 같은 역할의 사용처로 확대한다.

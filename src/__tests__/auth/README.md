# Auth tests

인증 테스트는 사용자 인증이라는 하나의 비즈니스 경계를 기준으로 이 디렉터리에 모읍니다.

- `unit/`: 소셜 제공자 및 Bottle Note API와의 요청·응답 계약, 토큰과 쿠키 변환, 서버 오케스트레이션
- `integration/`: 웹·인앱 로그인, 세션 복원, 토큰 갱신, 로그아웃과 리다이렉트 등 사용자 시나리오
- `support/`: 여러 인증 테스트에서 공유하는 JWT, 응답, 세션 fixture

테스트 이름은 구현 함수보다 비즈니스 규칙을 설명하고, 인증 동작 변경은 실패하는 테스트를 먼저 추가한 뒤 구현합니다.

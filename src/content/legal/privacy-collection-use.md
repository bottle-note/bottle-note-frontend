# 보틀노트 개인정보 수집·이용 동의

> 이 문서는 검토·승인 전 초안이며, 시행일이 확정된 후에 효력이 발생합니다.

## 1. 동의의 성격

이 동의는 보틀노트 회원가입과 로그인 기반 서비스 제공에 필요한 개인정보의 수집·이용에 관한 사항입니다. 개인정보 처리방침은 서비스의 개인정보 처리 현황을 공개하는 문서이며, 이 동의와 별도로 언제든지 확인할 수 있습니다.

## 2. 수집·이용 항목

| 구분                  | 내용                                                                                                                                                                    |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 수집·이용 목적        | 소셜 로그인 인증, 회원 식별 및 계정 관리, 로그인 상태 유지, 서비스 기능 제공, 부정 이용 방지 및 문의 처리                                                               |
| 수집·이용 항목        | 소셜 계정 식별자, 이메일 주소, 닉네임, 프로필 이미지, 소셜 로그인 유형, 최근 로그인 일시 및 서비스 이용 과정에서 이용자가 직접 작성·등록하는 정보                       |
| 보유·이용 기간        | 회원 탈퇴 시까지. 관계 법령에 따라 보존이 필요한 정보는 해당 법령에서 정한 기간 동안 보관합니다. 방문·API 이용 기록은 발생일로부터 90일간 보관합니다.                   |
| 동의 거부권 및 불이익 | 이용자는 동의를 거부할 수 있습니다. 다만 이 정보는 회원가입과 로그인 기반 서비스 제공에 필요하므로, 동의하지 않으면 회원가입과 로그인 회원 전용 기능 이용이 제한됩니다. |

## 3. 선택 동의와의 구분

마케팅 목적 개인정보 이용 및 광고성 정보 수신은 선택 사항이며, 이 동의와 별도로 받습니다. 선택 동의에 동의하지 않아도 보틀노트의 기본 서비스 이용에는 제한이 없습니다.

## 4. 동의 내용의 변경

수집·이용 목적, 항목, 보유·이용 기간 등 동의 내용이 변경되는 경우 운영자는 필요한 사항을 알리고, 필요한 경우 새 동의를 받습니다.
